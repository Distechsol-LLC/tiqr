# TiQR Web

> TiQR Web is made with
> - **[TypeScript](https://typescriptlang.org)**
> - **[Svelte](https://svelte.dev)**
> - **[Zod](https://zod.dev)**
> - **[Skeleton](https://skeleton.dev)**
> - **[Lucide](https://lucide.dev)**
> - **[Vite](https://vite.dev)**
>
> & is a static build the API serves, so it ships inside the `tiqr` executable.

## Install
```sh
bun i
```
## Develop
### Start Env
```sh
bun dev
```
### Preview Prod Build
```sh
bun serve
```
## Tools
### Fix Code (Biome + SV Check)
```sh
bun fix:s
```
### See Orphans (Knip)
```sh
bun orphans
```
## Test
### Run Watch
```sh
bun check:w
```
